# Buildmates Build Week demo package

This folder contains the editable production package for the under-three-minute Buildmates demo.

## Structure

- `01-script/`: locked narration and timecoded voiceover cue sheet.
- `02-storyboard/`: scene and transition production contract.
- `03-captures/raw/`: untouched product recordings and screenshots.
- `04-assets/`: approved generated concepts, saved surface bundles, and the real Codex task excerpt.
- `05-remotion/`: source composition and local render instructions.
- `06-renders/scenes/`: seventeen full-resolution scene clips for precise editing.
- `07-qa/`: desktop/mobile surface evidence, transition contact sheets, and final playback checks.
- `08-devpost/`: unpublished Devpost draft and submission asset checklist.
- `09-delivery/`: morning handoff and the remaining human submission steps.

## Hard boundaries

- Keep the live `yashns` profile and all Map, Build Graph, introduction, connection, room, and Circle demo fixtures.
- Do not publish the Devpost entry from this production folder.
- Real product footage is evidence. Motion graphics explain the idea but must not imply capabilities the live product does not have.
- Every custom profile, room, and Circle shown in the demo must pass rendered desktop and phone QA before selection.
- Every scene boundary must carry a visible object, shape, or motion into the next scene. A hard cut is allowed only when it is an intentional rhetorical break.
