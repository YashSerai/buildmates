What broke

The backend was steady. The UI needed discipline.

Copy leak

Internal edit instructions showed up as product text.

Bad contrast

White text on white surfaces made previews unreadable.

Layout drift

Overlaps, clipped headers, and dead space kept appearing.

Over-testing

Small edits triggered too much validation before a meaningful chunk was ready.

00:30 build -> 10:00 test loop

Skills, rules, and screenshots changed the output.

✓

✓

Copy rules

✓
