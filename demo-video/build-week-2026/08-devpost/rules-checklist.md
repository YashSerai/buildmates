# OpenAI Build Week submission checklist

Verified against the official OpenAI Build Week Devpost rules and FAQ on 2026-07-21.

- Deadline: July 21, 2026 at 5:00 PM Pacific.
- Track: Work and Productivity.
- Working project required.
- English project description required.
- Public repository with relevant license, or a private repository shared with the two reviewer addresses in the rules.
- Public YouTube demo video under three minutes.
- Video must include audio or voiceover.
- Video must clearly show the working product.
- Voiceover must explain what was built.
- Voiceover must explain how Codex was used.
- Voiceover must explain how GPT-5.6 was used.
- Do not use copyrighted music, third-party marks, or assets without permission.

Official references:

- https://openai.devpost.com/rules
- https://openai.devpost.com/details/faqs
- https://openai.com/build-week/
