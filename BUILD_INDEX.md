# Buildmates build index

Status: chat-native implementation in progress. Production release unchanged.
Updated: October 2, 2026.

Read [the active program](docs/product/chat-native/INDEX.md), then [the current checkpoint](docs/product/chat-native/CURRENT.md). The checkpoint is the restart authority for this work.

Buildmates is an agentic builder network used through ChatGPT web and Codex. Both hosts use one authoritative backend and the same verified account. Users can complete signup with a reviewed private profile; generated public pages and background tasks are optional. Authentication, source access, publication, and interpersonal consent remain real user choices.

The accepted scope is [the chat-native workstream](docs/product/chat-native/WORKSTREAM.md). Unresolved work belongs in [the issue queue](docs/product/chat-native/ISSUES.md). Verification belongs in bounded files under `docs/product/chat-native/qa/`, with explicit local, host, and deployment boundaries.

The July product and architecture specifications under `docs/aegis/specs/` remain the foundation except where the current user-approved direction supersedes Codex-only onboarding, mandatory publication, mandatory automation, or unsafe capability claims. The previous index is archived at [July build index](docs/aegis/archive/BUILD_INDEX-2026-07-21.md).

Release requires reviewed code, passing verification, actual host install/authentication evidence, independent-account consent and collaboration, honest public data, and deployment smoke for the exact source versions. A test fixture or a local browser harness is not proof of installation in ChatGPT or Codex.
