# Aegis project records

This directory keeps Buildmates planning and execution truth durable across sessions.

- `baseline/` records verified starting conditions.
- `specs/` contains approved product and architecture behavior.
- `plans/` contains executable implementation plans.
- `BASELINE-GOVERNANCE.md` defines evidence and change-control rules.
- `INDEX.md` records the active documents.

The root `BUILD_INDEX.md` is the fastest resume point.
